# Minecraft YouTube Launcher Mod

A client-side Fabric Minecraft mod that adds a YouTube-themed in-game launcher. Browse a set of Minecraft video searches with keyboard or mouse controls, then open the selected YouTube search in your system browser. Video playback happens in the browser, not inside Minecraft.

## Install

1. Install Minecraft 1.21.11, Fabric Loader, Fabric API, and Java 21 or later.
2. Place the mod JAR in your Minecraft `mods` folder.
3. Launch Minecraft using your Fabric profile.

## Use

1. Press `Y` to open or close the launcher. You can change this key in Minecraft’s Controls settings.
2. Use the up and down arrow keys or the mouse wheel to select a search.
3. Use the left and right arrow keys or the on-screen buttons to change pages.
4. Press `Enter` or `Space` to open the selected YouTube search in your system browser.
5. Press `Escape` to close the launcher.
